# 越韵里 · 江南戏院 v2

- Created: 2026-10-19, for this project.
- Authoring source: `public/js/yue-opera-village.js`.
- Original procedural architecture, with original canvas-generated stone, roof and plaque textures. No third-party mesh or photographic texture was copied into this asset.
- 23 buildings, including the central opera stage, two-storey viewing buildings, tea houses, residences, entrance and garden pavilions.
- GLB includes textures, building inventory, descriptive component names and shared mesh geometry.
- Layout references: Shaoxing courtyard opera theatres (CCTV), Wuzhen Water Theatre (official Wuzhen visitor guide). Reference links and the design explanation are in the delivered reference document.
- Runtime uses Three.js already bundled by this project; its existing MIT license applies to the library.
- The previous stage GLB files remain available as historical assets. The updated stage page constructs this new scene directly and no longer requests the previous stage GLB.
