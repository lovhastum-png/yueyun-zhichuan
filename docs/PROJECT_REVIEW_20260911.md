# 项目检查与修复记录（2026-09-11）

本轮重点检查前后端公共请求层、登录、课程列表、PDF 导入、OCR、课程阅读、课件及资源重新生成。保留工作区其他任务同时提交到文件中的改动，不将所有差异都归为本轮成果。

## 已修复的问题

| 问题 | 修复后的行为 |
| --- | --- |
| 输错密码被当成登录过期，并刷新登录页 | 登录接口保留原始业务提示，不触发过期跳转 |
| 重新登录后丢失原访问页面 | 登录跳转携带站内 next，成功后返回原页面 |
| HTTP 响应头收到后取消超时，正文可能永远等待 | 超时覆盖正文读取，支持取消请求 |
| 网关返回 HTML 时页面报解析错误 | 请求层转换为可读错误提示 |
| 首次进入加载所有功能页面 | 路由按需加载；入口 JS 约 179KB，gzip 约 59KB |
| 页面加载或渲染异常后白屏 | 错误边界提供重新加载和返回首页 |
| AI 问答、音频等互相消耗限流配额 | 每个限流器隔离计数 |
| 幂等保护超过 TTL 后重复执行仍在处理的请求 | 处理中持续保护，成功复用结果，失败允许重试 |
| 后端关闭时引用未导入的数据库连接池 | 补齐导入，关闭逻辑可访问连接池 |
| PDF 同一分片并发重试重复累计字节 | 同一上传串行处理写入、提交及取消；写盘处理短写 |
| 重复提交上传完成请求可能重复建课 | 同一上传完成请求互斥并复用 taskId |
| PDF 分片请求长期无响应 | 单次请求 30 秒超时，按现有策略自动重试 |
| 短暂网络故障把后台导入误判为失败 | 保留任务，退避重连，不引导立即重复上传 |
| 刷新后失去当前导入进度 | 同一浏览器标签会话按用户保存任务 ID |
| 部分 AI 资源失败却显示“全部完成” | 显示部分完成并提供课程内补生成提示 |
| 导入后缺少继续导入入口，处理中能换文件 | 增加继续导入入口，处理中锁定文件和标题 |
| 上传上限前后端不一致 | 当前运行的后端和 OCR 均为 100MB |
| 文字型 PDF 每页也运行 OCR | 优先提取有效文字；扫描页回退 OCR |
| OCR 文档和上传文件未显式关闭，超大页面可能占满内存 | 显式释放文档/文件，限制读取量和单页像素 |
| OCR 非法环境变量导致启动失败；线程限制不直接作用于 ONNX | 配置安全回退，显式设置 ONNX 计算线程 |
| 课程列表加载失败看起来像“没有课程” | 错误状态单独展示并可重试 |
| 快速切换列表或章节，被较早请求覆盖 | 只接受最新请求结果 |
| 资源重新生成失败/超时也提示成功 | 按真实终态提示；等待超时不冒充成功 |
| 重新生成先删除旧图谱和测验，AI 失败后内容丢失 | 先生成，再在数据库事务中替换；异常回滚 |
| 同一资源并发启动多次生成 | 启动阶段加锁，复用正在生成的状态 |
| PPT 预览空间受侧栏挤压，窄屏文字被裁切 | 课件独占主区域、放宽画布、增加全屏入口及窄屏布局 |
| 输入时左右键误翻页，PPT 重复下载与过早释放下载地址 | 编辑控件忽略翻页，下载增加忙碌状态，延后释放 URL |
| 弹窗焦点跑到背景，关闭后键盘位置丢失 | 初始聚焦、Tab 循环、Esc 关闭、恢复触发按钮焦点 |
| 登录输入标签和输入框未关联 | 添加 label/input 关联和注册密码自动填充类型 |

## 仍需在目标环境验证

- 尚未在目标 4 核 4GB Linux 服务器上执行多人压力测试，不能据此承诺并发人数。
- 外部 AI 接口、摄像头、麦克风、3D 和所有浏览器组合未逐一完成端到端验证。
- 导入任务仍为单 Node 进程内存任务；同标签刷新可恢复进度，但服务器重启不能自动续跑。进度丢失时界面会明确提示先检查课程中心，避免盲目重复导入。
- OCR 的文字提取是逐页启发式回退；复杂混排、目录定位及低清扫描的准确率仍需要真实资料抽检。
- 本轮扩大了 PPT 预览及改进导出体验；没有增加在网页中插入自定义图片的编辑器。
